# 制作物の共有場所

サオリのUIデザイン案、READMEの下書き、発表資料を共有するためのフォルダです。

## 置くもの

- UIの参考画像、画面デザイン、実装担当へ渡す素材
- READMEの下書き（例：`readme-draft.md`）
- 発表資料と発表原稿の下書き

## アップロード方法

GitHubでこのフォルダを開き、**Add file → Upload files** からファイルを選び、変更をコミットします。Gitを使う場合も、このフォルダにファイルを追加してプッシュできます。

画像の名前の例：`success-screen-v1.png`。修正案は `v2` など別名で追加すると、前の案と比較できます。

ここに置いたファイルは確認・受け渡し用です。採用前のデザインや発表内容は案として扱い、ゲーム画面への組み込みは担当者と確認して進めます。
