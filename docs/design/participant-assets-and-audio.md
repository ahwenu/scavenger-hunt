### 補完をやり直すときの指示

上表の参照元PNGを渡し、`transparent_background: true` を指定する。生成結果を `enhanced/` に置き、元画像を上書きしない。次の要点は再生成用の指示で、生成時の全文や乱数シードの保存ではない。同じ指示でも細部は変わる。

共通指示: 「参照画像と同じキャラクター、色、表情、ポーズを保ち、小さな原画を明瞭なアニメ調の高解像度素材として描き直す。輪郭と顔を読み取りやすくし、デザインを変えすぎない。透明背景、独立した1体、文字・UI・背景・追加キャラクターなし。元絵の全体を欠けさせない。」

| 素材 | 個別に保持する要点 |
| --- | --- |
| 判定ロボ | 白い小型ロボ、紺の顔ディスプレイとシアンの表情、赤い鉢巻、青いパーツ、虫眼鏡を使う原画の判定ポーズ |
| 成功の猫 | 金髪・猫耳・赤鉢巻とリボン・白と青の運動着。目を閉じて笑い、両手を上げて応援。**画面左のポンポンを青、右をピンク**にする（初回生成後に色を修正した） |
| 失敗の猫 | 金髪・猫耳・赤鉢巻・白と青の運動着。原画のうつむきと閉じた目を保つ。頭上の青い縦線を含む落ち込み表現 |
| 失敗ロボ | 白い小さな座り姿勢。紺ディスプレイに下がったシアンの目と悲しい口。赤鉢巻と右側のリボン、青い耳、胸の青い丸、前へ出した足。画面左の手に下げた虫眼鏡、頭上の青い縦線。全身と透明な余白を保つ |
| スタートの旗ロボ | 元の笑顔、赤い旗、黄色いメガホン、跳躍姿勢を維持する。白い外装とキャラクター内部を完全に不透明にし、透明部分は輪郭外と手足の間だけにする |

再生成後は `/design-preview` の対象画面で、表情・ポーズ・縦横比・表示サイズ・隣のUIとの重なりを確認する。PNGの画素数を増やしても、元のキャラクターと同一の細部になったことを意味しない。

## 音声・効果音・BGM

ファイルはすべて `apps/cloud/public/audio/` にある。声・効果音は **ElevenLabsで生成した素材**。BGMは2026-10-18のユーザー指定 `bgm.mp3` に差し替えた（生成元は未確認）。以前のBGMはElevenLabs製。[Suno用プロンプト](suno-karimono-bgm.md)は今後の生成・差し替え用として残す。アプリは配置済みMP3を再生し、プレイヤーのブラウザからElevenLabsやSunoへ生成要求を送らない。

オリジナル音声は「Karimono Cat Guide」と「Karimono Robot Judge」の2種を作成した記録がある。再生成に使うElevenLabsの声IDは猫 `L1a1fMXKqQal8VMfhqkL`、ロボ `e5Os5A3tGqBdsv9Fcv0g`。別アカウントから利用できるかは未確認。声IDは実行時の設定ではなく、配信時に必要なのは書き出したMP3のみ。

初期状態は音オフ。画面の音ボタンを押すとBGMとその画面の声を再生し、声は画面が変わると前の再生を止めて切り替える。音をオフにするとBGMと声を停止する。設定を保存する実装はなく、ページの再読込でオフに戻る。短い効果音は別のAudioで再生されるため、再生開始済みの効果音はオフ操作と同時には停止しない。音をオフにしている間の新しい効果音は再生しない。

音量はコード内の固定値。音声0.78に対してBGM0.16としているが、素材自体の音量差を自動調整する処理はない。端末の実音量とモバイルブラウザでの再生成功は未確認。再生エラーは画面を妨げず、ゲームの操作を継続する実装。

## Suno製BGMへの差し替え

1. [Suno用プロンプト](suno-karimono-bgm.md)の英語Styleとインストルメンタル用構成を使って生成する。日本語ブロックは内容確認用。112 BPM、運動会らしい明るさ、短い声と効果音の余地、歌なしが要点。
2. ループのつなぎ目で無音や急な音量差が出ない音源を選び、MP3で用意する。生成指示だけで継ぎ目が自然になる保証はないため、終わりから冒頭への接続を試聴する。
3. `apps/cloud/public/audio/game-loop.mp3` を差し替える。同じ名前ならコード側の参照変更は不要。別名にする場合は `ParticipantGame.tsx` のBGMパスも変更する。
4. 再読込後に音ボタンを押し、1周以上の再生、画面遷移、声と成功音との重なり、オフ操作を確認する。大きすぎる場合は素材音量またはBGMの `volume = 0.16` を調整する。

声も同名のMP3を置き換えて更新できる。素材ファイルの配信にはSuno・ElevenLabsのAPIキーをフロントエンドへ設定する必要はない。生成元・採用した版・差し替え日を本書に追記する。
