### 補完をやり直すときの指示

上表の参照元PNGを渡し、`transparent_background: true` を指定する。生成結果を `enhanced/` に置き、元画像を上書きしない。次の要点は再生成用の指示で、生成時の全文や乱数シードの保存ではない。同じ指示でも細部は変わる。

共通指示: 「参照画像と同じキャラクター、色、表情、ポーズを保ち、小さな原画を明瞭なアニメ調の高解像度素材として描き直す。輪郭と顔を読み取りやすくし、デザインを変えすぎない。透明背景、独立した1体、文字・UI・背景・追加キャラクターなし。元絵の全体を欠けさせない。」

| 素材 | 個別に保持する要点 |
| --- | --- |
| 判定ロボ | 白い小型ロボ、紺の顔ディスプレイとシアンの表情、赤い鉢巻、青いパーツ、虫眼鏡を使う原画の判定ポーズ |
| 成功の猫 | 金髪・猫耳・赤鉢巻とリボン・白と青の運動着。目を閉じて笑い、両手を上げて応援。**画面左のポンポンを青、右をピンク**にする（初回生成後に色を修正した） |
| 失敗の猫 | 金髪・猫耳・赤鉢巻・白と青の運動着。原画のうつむきと閉じた目を保つ。頭上の青い縦線を含む落ち込み表現 |
| 失敗ロボ | 白い小さな座り姿勢。紺ディスプレイに下がったシアンの目と悲しい口。赤鉢巻と右側のリボン、青い耳、胸の青い丸、前へ出した足。画面左の手に下げた虫眼鏡、頭上の青い縦線。全身と透明な余白を保つ |
| スタートの旗ロボ | 元の笑顔、赤い旗、黄色いメガホン、跳躍姿勢を維持する。白い外装とキャラクター内部を完全に不透明にし、透明部分は輪郭外と手足の間だけにする |

再生成後は `/design-preview` の対象画面で、表情・ポーズ・縦横比・表示サイズ・隣のUIとの重なりを確認する。PNGの画素数を増やしても、元のキャラクターと同一の細部になったことを意味しない。

## 音声・効果音・BGM

声とBGMは `apps/cloud/public/audio/` にある。声は **ElevenLabsで生成した素材**。現在の効果音はリポジトリにある **OtoLogicの11種類**を使い、`apps/web/sounds/` から既存Cloud資産へ同期して `/sounds/` で配信する。出典・加工内容は[効果音仕様](../15-sound-effects.md)を参照。

BGMは2026-10-18のユーザー指定 `bgm.mp3` に差し替えた（生成元は未確認）。以前のBGMはElevenLabs製。[Suno用プロンプト](suno-karimono-bgm.md)は今後の生成・差し替え用として残す。アプリは配置済みMP3を再生し、プレイヤーのブラウザからElevenLabsやSunoへ生成要求を送らない。

当初のオリジナル音声は「Karimono Cat Guide」と「Karimono Robot Judge」の2種を作成した記録がある。ElevenLabsの声IDは旧猫 `L1a1fMXKqQal8VMfhqkL`、ロボ `e5Os5A3tGqBdsv9Fcv0g`。猫は後述の「さっちゃん」へ差し替え、ロボットは既存音声を維持した。別アカウントから声IDを利用できるかは未確認。声IDは実行時の設定ではなく、配信時に必要なのは書き出したMP3のみ。

猫9本の長さは後述の採用記録にまとめる。ロボット・BGM・旧効果音の現物は以下。

| ファイル名 | 用途 | 現物の長さ | 音量（0〜1） |
| --- | --- | ---: | ---: |
| `judging-ja.mp3` | 判定中画面 | 4.97秒 | 0.78 |
| `camera-click.mp3` | 旧撮影音。OtoLogicへ置換し現在の画面からは未使用 | 1.00秒 | — |
| `success-chime.mp3` | 旧成功音。OtoLogicへ置換し現在の画面からは未使用 | 2.00秒 | — |

追加指示により初期状態は音オン。端末に保存したオフ設定は尊重する。最初の参加・タップ操作を契機に、再利用する3つのHTMLAudio要素でBGM・声・効果音を起動する。音ボタンでオフにすると、再生中の効果音・声・BGMと待機中の演出も止める。設定は `karimono:sound` に保存する。

声は短い効果音の後へずらして再生し、新しい案内が入ったら前の案内・待機を止める。タブ非表示でも全音を止め、復帰時にはBGMだけを再開する。初回取得・定期同期・提出の再確認による過去の結果音は抑える。マナーモードでの再生に向けた方針と未確認範囲は[ADR-0018](../adr/0018-participant-media-audio.md)を参照。

音量はコード内の固定値で、音声0.78、BGM通常0.16・声の間0.07。猫・ロボットの声は `playbackRate = 0.85` と `preservesPitch = true` でゆっくり再生する。生成時の速度と再生時の速度は区別する。素材自体の音量差を自動調整する処理はない。端末の実音量とモバイルブラウザでの再生成功は未確認。再生エラーは画面を妨げず、ゲームの操作を継続する実装。

## Suno製BGMへの差し替え

1. [Suno用プロンプト](suno-karimono-bgm.md)の英語Styleとインストルメンタル用構成を使って生成する。日本語ブロックは内容確認用。112 BPM、運動会らしい明るさ、短い声と効果音の余地、歌なしが要点。
2. ループのつなぎ目で無音や急な音量差が出ない音源を選び、MP3で用意する。生成指示だけで継ぎ目が自然になる保証はないため、終わりから冒頭への接続を試聴する。
3. `apps/cloud/public/audio/game-loop.mp3` を差し替える。同じ名前ならコード側の参照変更は不要。別名にする場合は `audio/media-audio.ts` のBGMパスも変更する。
4. 再読込後に最初の操作で音を始め、1周以上の再生、画面遷移、声と成功音との重なり、オフ操作を確認する。保存済みオフの場合は音ボタンでオンへ戻す。大きすぎる場合は素材音量または通常時・声再生中のBGM音量を調整する。

声も同名のMP3を置き換えて更新できる。素材ファイルの配信にはSuno・ElevenLabsのAPIキーをフロントエンドへ設定する必要はない。生成元・採用した版・差し替え日を本書に追記する。
