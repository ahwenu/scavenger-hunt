ZIPを展開して `index.html` をブラウザーで開いてください。外部サービスや通信は不要です。名前・用途で検索し、明色/暗色背景で透過を確認できます。カードを押すと元の切り抜きとの比較が表示されます。

## 実装時の使い方

- キャラ・表情の切り替えには `09-aligned-sprites` を使うと表示枠が揃います。画像は1x原寸です。
- 通常のPNGは余白を詰めてあります。元の位置に配置したい場合は `sourceRect` と `trimOffset` を使ってください。
- 文字・タイマー・得点・順位・進捗・ランキングの名前は画像に焼き込まれています。可変値、翻訳、読み上げ対応はHTMLテキストとCSSで実装してください。
- ボタンは `<button>` に画像を配置し、操作名を `aria-label` で指定してください。背景イラストには `alt=""` を指定できます。
- 原寸以下での利用を基本にしてください。元画像は1536×1024px、表情は約100pxです。高解像度画面や大きなキャラ表示には、別途高解像度の元原稿が必要です。

```html
<img src="09-aligned-sprites/girl-cheer.png"
     width="160" height="160" alt="応援するキャラクター">

<button type="button" aria-label="ゲームスタート">
  <img src="05-ui/button-start.png" alt="">
</button>
```

## 元画像から分離できない部分

- `06-screen-parts` は背景・文字・キャラクターが合成された画面見本の切り抜きです。独立した透過レイヤーではありません。
- 背景4枚にも旗・風船・看板などが描き込まれています。隠れている背景、文字の下、キャラクターの後ろは復元していません。
- `01-characters/robot-guide.png` は、原画で白い胴体の輪郭が背景に溶け込んでいます。この1点は背景付き参照画像として保持しています。透過が必要な案内役には、基本ポーズなど他のロボットを使ってください。
- 表情素材は胸元で切れた原画です。下半身や欠けた髪を補完していません。隣の絵と近接している細い輪郭は、元原画のままです。
- 半透明の元レイヤーは存在しないため、透過版は外周に連結した淡色背景を除いた切り出しです。明色/暗色で点検していますが、元の背景色が細い縁に残る場合があります。元の切り抜きも必ず同梱しています。
- カラープロファイルの正規化は行っていません。WebではsRGB表示を基準に最終確認してください。

## manifestの座標

`sourceRect: [x, y, width, height]` は元画像左上を原点とするピクセル座標です。`trimOffset: [x, y]` は、その切り抜きから余白を詰めた量です。通常PNGの画素 `(u,v)` は、元画像の `(sourceRect[0]+trimOffset[0]+u, sourceRect[1]+trimOffset[1]+v)` に対応します。

`transparency` は通常PNGの透過処理の有無です。`alignedFile`、`alignedCanvas`、`alignedOffset` は共通キャンバス版の情報です。背景付きの案内ロボットも、キャンバスの外側にだけ透明な余白があります。

## 検証範囲

すべてのPNGについて読込・寸法・ファイル対応・透明領域の有無を検査。元切り抜きのRGB画素が出典矩形と一致すること、および透過PNGの不透明画素が元のRGBを保持することを照合しています。元画像はハッシュで同一性を確認しています。共通キャンバス版は拡大なしです。

実際のアプリへの組み込み、実機での表示、動的UIの実装はこの素材集には含みません。

一覧HTMLはファイル参照・埋め込みデータ・JavaScript構文を検査済みです。ブラウザー検証ツールがローカルの `file:` URLを許可しないため、HTMLの実表示と操作は未確認です。
