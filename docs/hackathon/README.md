## 根拠の優先順位

1. 画面配置・担当などはユーザーの最新指示とAccepted ADR。
2. 現在の動作は実コードと、実施主体を明記した検証記録。
3. 未実装の仕様はProposed ADRと `docs/01`〜`11`。会議メモは意図の背景として読み、後の決定との差を残す。
4. 審査・公開条件は[主催のLumaページ](https://luma.com/OpenAIDevDay2026CommunityHackathonTokyo)。17:15の提出とGitHub・公開URLの連携は、2026-10-18 13:18のXチーム共有による。

議事録には「ホストも参加者もPlugin Extensions」「最初の正解で次のお題が増える」案があり、その後のAccepted ADRでは参加者はスマホブラウザ/Sites、ホストはPlugin Extensionsとなっています。進行ルールは現在の案同士にも差があるため、[未決事項](domain/goal-and-decisions.md)として扱います。

秘密値、トークン、会場Wi-Fi情報、個人の写真やチームDM全文はここへ転記しません。
