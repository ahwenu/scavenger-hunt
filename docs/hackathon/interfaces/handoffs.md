## 接続で必要な最小契約

| 境界 | 渡すもの | 受け取るもの | 未決・注意 |
| --- | --- | --- | --- |
| Pluginホスト → Sitesゲーム | 部屋作成・開始・進行操作とホスト権限 | 部屋、参加URL/QR、参加者、順位、状態version | 現在のPluginは未接続/デモ。Sites接続アダプターと認可が未実装 |
| Sitesゲーム → 独立AI API | お題生成要求ID、判定時の`challengeId`とJPEG写真、サービス用認証 | お題条件、合否・不明/処理失敗 | APIはローカル専用で20分の一時保持。公開先・期限・再起動時の扱いが必要 |
| スマホ画面 → Sitesゲーム | 参加、撮影写真、提出の再送ID | お題、締切、提出状態、合否、確定得点・順位 | 既存デモのHTTP形と04の契約案に差がある。使う形を1つに揃える |
| デザイン画像 → スマホ画面 | 各状態の見本・文言・素材 | 実データ・カメラ・通信をつないだ画面 | 画像未受領。Akibakoさんの案を先に確認してから見た目を実装 |

OpenAIキー、サービス用トークン、秘密ファイルの実パスをチャットやHTMLへ載せません。サービス用認証を参加者のブラウザへ渡さない点は[11](../../11-api-integration.md)に沿います。
