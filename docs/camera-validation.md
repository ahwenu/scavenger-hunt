# カメラ・ホスト画面の検証

2026-10-18 JST。公開サイトは [AI借り物競争](https://ai-karimono-race.ahwenu.chatgpt.site/)。自動テスト、実ブラウザでの確認、未検証の実機撮影を分けて記録します。

## 自動テスト

`tests/camera.test.mjs` はDOM・カメラAPI・画像デコーダーを注入した13件の動作テストです。カメラの実映像を撮影した試験ではありません。

- 許可要求は明示操作だけで実行。拒否後の状態更新では再要求せず、明示的に再試行できます。
- カメラ非対応・機器なしでは写真選択へ移れます。選択した写真は確認ボタンなしで送信処理へ渡します。
- シャッター連打は1回の撮影・送信に限定。202受付・判定待ちはロックし、不合格や送信失敗後は次の撮影へ戻ります。
- 休止・非表示・ページ離脱・破棄でトラックを停止。遅れて許可されたストリームも解放します。ロビーからラウンドへの移行では映像を保ちます。
- ラウンド切替前の撮影・送信コールバックが、新ラウンドへ結果を混入しません。
- bitmap APIがない場合・復号に失敗した場合もImage要素で復号し、必ず960px以下のJPEGへ再圧縮します。元のJPEG/PNGバイトを直接送る経路は使いません。ObjectURLは成功・失敗・破棄時に解放します。
- ライブ撮影は中央のobject-fit:cover表示と同じ範囲を切り出します。1920×1080入力で、縦300×400表示は(x555,y0,w810,h1080)、横400×200表示は(x0,y60,w1920,h960)となり、毎回表示寸法を読み直すことを確認しました。

`tests/camera-app.test.mjs` は実際のapp.jsの受付・状態反映処理をVMで実行する4件の結合テストです。HTTPと表示先を境界で置き換えています。

- 登録済み・お題なし・仮受付なしの初回ロビーを正常表示する回帰テスト。
- 送信後に応答を失った場合、状態確認だけでは自動再送しません。明示的な再試行は同じ画像バイト・受付キー・デモ結果を再利用します。
- サーバーに既存受付が見つかった場合、明示再試行でも追加POSTを行いません。
- 通信失敗は不合格に見せずエラーとして保持し、通信復旧後の状態取得でも消しません。

最終実行では全35件が成功しました（カメラ部品13件、app.js結合4件を含む）。

既存のサーバー結合テストは実JPEGの202受付、合格・不合格・エラー、重複防止、合格イベントの原子的保存、部屋分離と順位を検証します。自動テストは有料API呼び出しを行いません。

以下は親エージェントが実ブラウザで確認した記録です。模擬DOMの結果や生成したスクリーンショットではありません。

390×844の参加画面で、端末写真選択から自動202受付→デモ不合格→再挑戦→デモ合格・2位表示を確認しました。不合格理由はサーバーの確定した返値を表示します。[不合格画面](camera-rejected-390x844.png)・[成功画面](autumn-camera-success.png)。

カメラ許可が保留の状態から明示的に中止し、休止状態と写真選択へ戻れることを確認しました。カメラのハードウェア許可・実映像取得は行っていません。

独立したローカル試験サーバーだけを停止し、写真送信で「送信できませんでした」と通信確認の案内が出ること、サーバーを再起動して通信が戻ってもエラー表示が残ることを確認しました。不合格表示に置き換わりません。[通信失敗画面](camera-network-error.png)。

別参加者の実際のデモ投稿を202受付・DB合格へ進め、カメラ部品の上に「運動会ランナーさんがいま1位通過」と表示されることを確認しました。映像許可前の部品ですが、通知は実際の確定イベントによるものです。[カメラ上の通過通知](camera-cutin-390x844.png)。

## 公開APIと測定範囲

`public-smoke.json` はログイン・プラットフォームCookie・認証回避なしの公開HTTP試験です。最新版の公開試験も成功しました。初回参加から期限まで30,000ms、ホスト開始操作なしで期限後405msに自動開始し、権限、QR、部屋分離、デモ画像受付と合格イベントを確認しました。

`public-reference-smoke.json` は別の実AI試験です。実際のAgents検索・参考写真取得から公開配信、70同時画像取得、コピー拒否、別のバナナ写真のDecisions API合格まで成功しています。参考写真そのものは409、圧縮したコピーは不合格（確率[0.02,1,0.97,0.86,0]）、別写真は合格（[0.93,1,0.98,1,0.99]）、永続イベント74・1位でした。公開画像70取得は全件成功、1119ms。これは実機カメラでその場に撮影した証明ではありません。

実機iPhone/Androidのカメラ許可、実映像、端末回転中の撮影、実際のカメラ画質、ブラウザ固有の画像復号と会場Wi-Fiは未検証です。中央切り出しは自動テストで確認しましたが、ハードウェア映像を使った目視照合はしていません。70人負荷は既存のデモHTTP試験であり、70台実機や70件有料AI同時判定の結果ではありません。
