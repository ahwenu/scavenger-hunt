# ADR-0012: 運動会・猫耳キャラクターの素材をホスト用レスポンシブUIへ取り込む

- 状態：Accepted
- 作成日：2026-10-18
- 最終更新：2026-10-18
- 関係担当：Akibako さん、Plugin Extensions画面は未定（Ahwenu）、Ahwenu
- 決定の根拠：ユーザーによる、運動会・猫耳キャラクターのスマホ案を参考にPlugin Extensions UIを実装する明示指示。Acceptedはテーマと実装境界の採用を表し、新UIの動作検証完了を意味しない
- 置き換えるADR：なし。ホスト画面配置と既存のQR・MCP・Sites契約を維持して表示を具体化
- 後継ADR：なし

## 背景

運動会テーマの素材集とスマホ画面案が用意された。ホストはPlugin Extensionsで部屋・参加者・進行・順位を扱うため、スマホ画面の色・キャラクター・雰囲気を、ホストの操作と情報量に合わせる必要がある。

## 決定

- [運動会テーマ素材ガイド](../design/sports-day-ui-assets-v1/README.md)とスマホ案を参照し、青空・旗・校庭・猫耳キャラクター・ロボットをホスト画面の視覚表現に使う。名称・チーム・キャッチコピーはADR-0007を維持する。
- スマホ案を参考に、広いホストパネルでは参加QR・お題/進行操作・参加者・ランキングを見渡せる配置とし、狭い幅では縦へ再配置する。スマホ画面の画像をそのまま操作画面として貼り付けない。
- 必要な原素材だけを `plugin/src/ui/assets/` へ同梱し、HTMLのdata URLへバンドルする。配布後に親の `docs/` や外部画像サーバーへ依存しない。
- 素材は原寸以下で使い、焼き込まれたタイマー・得点・名前・順位などを実データとして表示しない。可変値はHTMLテキスト/CSS、操作は実際のbuttonとし、読み上げ名を持たせる。装飾画像は必要に応じて空altとする。
- 参加QRは既存のローカル白黒SVGと余白を保ち、白い領域を確保する。装飾・透過・重ね絵でQRを覆わず、参加リンクの代替導線を残す。外部QR通信とCSP緩和は追加しない。
- 既存のMCPブリッジ、Sites認可、勝利数順位、ラウンド操作、未接続/デモ/実接続の区別を保つ。AIやゲームルール、API契約、Sites配備の決定は変更しない。

## 代替案と理由

スマホ画面見本を一枚の画像として拡大表示する案は、ホストの情報量と動的表示・操作・読み上げに対応しにくい。素材を親docsから直接参照する案は単独配布時の可搬性を失うため、必要画像と動的なHTMLを組み合わせる。

## 影響とトレードオフ

ビルド済みHTMLは画像を含む分だけ大きくなる。採用素材を絞り、出典は素材ガイド/manifestで追えるようにする。元原稿の解像度を超える大きなキャラクター表現は行わない。既存のQR読取と操作性を、装飾追加後に再確認する必要がある。

## 検証・見直し条件

0.3.0で型チェック・21件のテスト・ビルド、通常/共有配布物の可搬性、公式CLIのインストール・有効化が成功。インストール済みserver/widgetのSHA-256はdistと一致した。使用した原素材8点は元ファイルとbyte単位で一致し、合計294,077 bytes、data URLで392,288 bytes。単独widgetは1,211,293 bytes。

インストール済みの未改変HTMLを、公式AppBridge/PostMessageTransportを使うsandbox iframe（`connect-src none`、画像はdata URLのみ）の検証ホストで表示して、1280pxと390px幅を確認した。UIの部屋作成操作で実Sitesへ部屋を作り、両幅の画面画像をmacOS Visionで読取してQRと参加URLの完全一致を確認。参加ページの匿名GETは200・リダイレクトなし。参加者0人で準備/開始が無効になることも確認した。

390px幅の別MCPではデモを明示的に選び、3チームのサンプル生成→準備→開始→結果の30/20/10ランキング更新を画面操作で確認した。これはサンプルの確認であり、実Sitesの勝利数順位へ混ぜていない。

証拠画像はGit対象外の `plugin/artifacts/` に保存：`sports-host-welcome-0.3.0.png`、`sports-host-qr-0.3.0.png`、`sports-host-390-0.3.0.png`、`sports-host-390-qr-0.3.0.png`、`sports-demo-ranking-390-0.3.0.png`。

ネイティブ拡張パネルの直接クリック、今回の新規参加登録・有料AI呼出は未実施。キーボード操作・実機・複数人負荷の評価も、上記の画面/QR確認だけで完了とは扱わない。この変更のcommit/pushは未実施。
