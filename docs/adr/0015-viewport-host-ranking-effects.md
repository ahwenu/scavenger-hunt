# ADR-0015: ホスト画面を一画面に収め、ランキング変化を視覚演出する

- 状態：Accepted
- 作成日：2026-10-18
- 最終更新：2026-10-18
- 関係担当：Akibako さん、Plugin Extensions画面は未定（Ahwenu）、Ahwenu
- 決定の根拠：ユーザーの「Plugin Extensions側のUIをスクロールなしでも成立するように変更」「ランキングの追加や変更などは随時派手な演出で表現」という明示指示。Acceptedは方針の採用であり、実装・配備・実機確認の完了を意味しない
- 置き換えるADR：[ADR-0012](0012-sports-day-host-ui.md)の画面配置。運動会テーマ・同梱素材・QR・接続境界は継続する
- 後継ADR：なし

## 背景

従来はヒーロー、招待、進行、ランキング、参加者、独立AI、クレジットが縦に続き、小さなPlugin Extensionsパネルや多数参加時にスクロールが必要だった。進行操作と得点変化を常に把握できる配置が求められた。

## 決定

- Plugin Extensionsの表示領域に合わせて主画面を構成する。広い画面は招待・進行・ランキングを並べ、狭い画面はタブで切り替える。装飾の紹介領域は圧縮する。
- 人数に応じて無制限に縦へ並べず、参加者とランキングをページで切り替える。共通ヒント・独立AIの確認・クレジットなどは明示操作で表示し、主画面の進行操作を押し下げない。単に内容を切り捨ててスクロールバーを消す方式にはしない。
- サーバーが返す確定順位・得点を比較し、新規追加・加点・順位上昇・首位交代・最終結果を、速報表示、色、行や得点の動き、紙吹雪などで知らせる。クライアントで得点や順位を作らない。
- 初回・同じ状態の定期同期・部屋切り替えでは過去の変化を再演出しない。通信復帰や非表示からの復帰も新しい比較基準とし、多数の更新は集約して最新状態を優先する。
- 演出は操作を覆わず、読み上げ向け通知を用意する。動きを減らす設定では静的な強調へ切り替える。効果音はADR-0014の既存監視に委ね、ランキングで二重再生しない。
- 編集範囲は自己完結した `plugin/` と関連文書。SitesのAPI、認可、DB、ゲーム規則、参加者画面は変更しない。配備は新しいPluginビルドの共有物生成とローカルインストールで行い、既存のSites接続・独立AI接続の秘密設定参照を引き継ぐ。

## 代替案と理由

ページ全体を縮小する方式は文字・操作・QRの判読性を損なう。各カードにスクロールを設ける方式はユーザーの要件を満たさない。更新のたびに全行を演出する方式は、2秒ポーリングや100人の更新で重要な変化を埋もれさせるため採用しない。

## 影響とトレードオフ

狭い画面ではすべての情報を同時に表示せず、タブとページ切り替えで到達する。実順位はサーバーの確定値を維持する。運動会素材と音源は引き続きHTMLに同梱し、追加の外部配信や依存パッケージを要求しない。

## 検証・見直し条件

型チェック・ランキング差分テスト・既存テスト・独立ビルド・通常/共有配布物の可搬性を確認する。複数の幅と高さ、多人数、長い名前、エラー、ヒント、AI表示、動きを減らす設定で、内容や操作が切り捨てられないことを確認する。実施結果と実機未確認範囲は[ホスト画面仕様](../08-plugin-extensions.md)へ追記する。

0.4.0の型チェック・39件（ランキング差分12件）・HTML/MCPビルド、通常/共有配布物の可搬性、11 MCPツール・未接続/明示デモが成功。画面と配備の結果は08へ記録する。

ローカルfixtureで9画面サイズ・100人の一覧・長文/改行の全文・進行/ヒント操作・ランキング連続変化・通信復帰の240項目が成功し、ブラウザ例外0。390×600/900×500のQR読取も成功。実Sitesやネイティブ拡張パネルの成功とは区別する。
