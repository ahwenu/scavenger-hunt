# ADR-0005: MVPの範囲とサーバー主導の採点・締切の案

- 状態：Proposed
- 作成日：2026-10-18
- 最終更新：2026-10-18
- 関係担当：全員
- 決定の根拠：開発方針文書のMVP初期案。数値はユーザー確定値ではない
- 置き換えるADR：なし
- 後継ADR：なし

## 背景と提案

最初は1チーム1代表端末、最大10チーム、共通3問、1問120秒、合格10点、各問最大5提出とする案。完成版の複数端末・参考写真・履歴等と分け、会場でゲーム全体が成立する範囲を優先する。

締切はサーバー受付時刻、加点は一意な記録で確定する。締切後30秒の確定猶予、2秒ポーリング、期限切れ処理の失敗確定を提案する。全数値の詳細と整合性は01・04・05を参照する。

## 代替案と理由

チームごとの進行、速度加点、複数端末同時提出は競合と公平性の処理を増やすためMVPから外す案。端末で得点・締切を確定する方式は採点の正本が分散するため採用しない案とする。

## 影響とトレードオフ

同期の即時性には限界があり、同点は同順位となる。冪等性、同時提出制限、遅延結果の排除、通信復帰を実装する必要がある。

## 検証・見直し条件

会場条件とAPI時間を測定し、問題数・時間・人数・試行回数を関係担当で確定する。二重加点、締切境界、AI中断、次問の二重操作を検証する。現在の数値は性能保証ではない。
