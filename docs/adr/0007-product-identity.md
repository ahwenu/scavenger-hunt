# ADR-0007: 制作チーム名・アプリ名・キャッチコピーを揃える

- 状態：Accepted
- 作成日：2026-10-18
- 最終更新：2026-10-18
- 関係担当：全員
- 決定の根拠：ユーザーが指定した現時点の名称情報
- 置き換えるADR：なし
- 後継ADR：なし

## 背景と決定

制作チーム名を「ONE LEASE」、アプリ名を「カリモノ」、キャッチコピーを「借り物王に俺はなる！」とする。Project.md、参加入口、ホスト拡張などのユーザー向け表示を揃える。現在の指定を記録するもので、将来の変更を妨げない。

## 代替案と理由

従来の「AI借り物競争 / Scavenger Hunt」は説明・リポジトリ名として残せるが、ユーザー向けアプリ名には指定された「カリモノ」を使う。

## 影響とトレードオフ

画面実装時に名称を反映する。制作チーム名とプレイヤーが入力する参加チーム名は区別する。Gitリポジトリ名、フォルダ名、内部API識別子、既定の著作権表記は名称指定だけを理由に変更しない。

## 検証・見直し条件

文書には反映済み。実画面は未実装のため、モバイルと拡張の初回表示確認時に表記を確認する。名称が変わる際は後継ADRを作成する。
