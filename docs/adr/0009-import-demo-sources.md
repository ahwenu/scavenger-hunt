# ADR-0009: デモのソースをローカルクローンから新規ファイルとして取り込む

- 状態：Accepted

- 最終更新：2026-10-18

- 決定の根拠：ユーザーによるローカルクローン・取り込み・新規コミットとプッシュの指示
- 置き換えるADR：なし
- 後継ADR：なし

## 背景と決定

`https://github.com/ahwenu/demo-app.git` をローカルへクローンし、追跡ファイルを現在のリポジトリへコピーする。GitHub上のファイル移動や元リポジトリの履歴マージは行わない。

元の配置と内容を維持し、競合するREADMEだけは `docs/imported/demo-app-README.md` に保存する。既存の方針文書と作業中のPlugin Extensionsの変更は保持し、取り込み分と混在させてコミットしない。

## 代替案と理由

Gitの履歴マージではなく、ユーザー指定の新規コミットとして取り込む。Sitesを直下へ移す既存案の適用はコード構成の変更を伴うため、この取り込みと分ける。

## 影響とトレードオフ

現状のSitesルートは `apps/cloud/`。09のルート配置案は未実現のままとする。取り込んだブラウザホスト・ゲームルール・APIは現方針と異なるため、Plugin Extensionsや正式APIへ接続する前に差分を確認する。

## 検証・見直し条件

取り込み対象と元ファイルの一致、Gitのステージ範囲、構文を確認する。元デモの過去の公開/AI検証結果を本環境の成功記録に置き換えない。今回はアプリ起動、有料API実行、Sites配備は行わない。
