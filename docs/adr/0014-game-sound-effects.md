# ADR-0014: モバイルとPlugin Extensionsに無料素材のゲーム効果音を同梱する

- 状態：Accepted
- 作成日：2026-10-18
- 最終更新：2026-10-18
- 関係担当：mae さん（モバイル）、Akibako さん（UI）、Plugin Extensions画面は未定（Ahwenu）、Ahwenu（配信・組み込み）
- 決定の根拠：ユーザーの「モバイル側もPlugin Extensions側も必要なタイミングに無料サイトの派手な効果音を設定する」という明示指示。Acceptedは演出と同梱方針の採用であり、実機試聴の完了を意味しない
- 置き換えるADR：なし
- 後継ADR：なし

## 背景

従来のモバイルには正解/不正解の簡単な合成音だけがあり、Pluginには効果音・切替がない。スマホブラウザの自動再生制限、ポーリングによる重複、単独Plugin配布を考慮する必要がある。

## 決定

- OtoLogicのCC BY 4.0素材を取得・短縮・音量調整して、両画面に作者・ライセンス・加工内容を表示する。取得元と加工量をmanifestで追えるようにする。
- 操作、参加、撮影、写真受付、お題開始、正解、不正解、残り5秒、受付終了、結果発表、最終終了に対応する。派手さはピンポン・オケヒ・キラキラ・ロックの音色で表現する。
- ユーザー操作でWeb Audioを起動し、端末別ON/OFF、非表示時停止、優先度、クールダウン、遅延破棄を設ける。初回取得では過去の演出を再生しない。
- モバイルは同一オリジンのMP3を使い、Cloudの資産生成とWorker配信へ必要なバイナリ対応だけを追加する。Pluginはdata URLへ埋め込み、親フォルダや外部音源サーバーを参照しない。
- サーバーのゲーム状態と確定得点を音へ変換するだけとし、API/採点/認可/AI処理を変更しない。今回の追加指示の範囲で `apps/web`、Cloud配信資産、Plugin UIを変更する。

## 代替案と理由

合成音だけではユーザーが求める音色の幅に乏しい。外部サイトへ毎回直接アクセスする方式は再生遅延・通信依存があり、自己完結したPlugin配布を損なう。各プラットフォームで新しい音声ライブラリを導入する必要はなく、標準Web Audioと同梱MP3を採用する。

## 影響とトレードオフ

音源は約165KB、Pluginではbase64分だけHTMLが増える。独立ビルドを保つため再生・監視コードを両方へ同梱し、テストで一致を保つ。スピーカーの音量とブラウザの許可状態は端末側に依存する。全員が同じ会場で音を出す場合はホスト/参加者各画面のOFFを使える。

## 検証・見直し条件

[効果音仕様](../15-sound-effects.md)にテスト・ビルド・ブラウザ確認結果を記録する。実機試聴・公開Sites再配備・インストール済みPlugin更新は別途実施し、ソースのビルド成功と混同しない。
