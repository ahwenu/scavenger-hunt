# ADR-0004: お題生成と写真判定をアダプターで分離する案

- 状態：Proposed
- 作成日：2026-10-18
- 最終更新：2026-10-18
- 関係担当：Ahwenu、さが さん、mae さん
- 決定の根拠：既存のAI連携案。利用権限・精度・速度は未検証
- 置き換えるADR：なし
- 後継ADR：なし

## 背景と提案

お題生成と写真判定を内部アダプターで分ける。Agents APIとDecisions APIをそれぞれ第一候補にし、正規化した結果だけをゲームサービスへ渡す。生成の代替候補はResponses API、生成失敗時はプリセットを用意する。AIに得点を決定させない。

実装経過：独立APIは[ADR-0010](0010-independent-ai-api.md)に従い、標準生成をResponses Structured Outputs、参考写真付き生成だけをAgentsの明示オプションとした。旧Agents方式の文章生成でセッション後処理失敗を確認。参考写真付きの初回試験は原因未特定の502で、成功は未確認。独立APIは自動プリセット補完を行わない。ゲーム側の手動プリセット選択・複数問準備・採点結合の案は引き続き未検証。

## 代替案と理由

ゲーム処理が外部API形式に直接依存する案は、サービス変更時の影響が大きい。すべてを同じAI処理で実行する案より、生成と判定の評価・制限を分けやすい構成を提案する。

## 影響とトレードオフ

アダプター実装と評価用写真が必要になる。合格・不合格・不明と通信失敗を分離し、保存と加点確定はさが さんのゲームサービスが行う。

## 検証・見直し条件

利用権限、実写真での誤合格、曖昧写真、処理時間、費用、Workers互換性を確認してモデルとAPIを確定する。閾値や時間予算は検証前の仮値のまま採用済みにしない。
