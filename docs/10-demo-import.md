# デモアプリの取り込み

2026-10-18、ユーザーの指示に従い `ahwenu/demo-app` を別のローカルフォルダへクローンし、その追跡ファイルを本リポジトリへ取り込んだ。元リポジトリのGit履歴は統合せず、本リポジトリの新規ファイルとしてコミットする。GitHub上のファイル移動や元リポジトリへの変更は行わない。

## 現在の配置

| パス | 内容 |
| --- | --- |
| `apps/cloud/` | Sites向けアプリ、D1/R2設定、マイグレーション、独立した依存とビルド設定 |
| `apps/server/` | ローカル開発用のNodeサーバー・ゲーム処理 |
| `apps/web/` | デモのブラウザ画面・カメラ処理・静的素材 |
| `apps/shared/` | デモ側で共有する処理 |
| `scripts/`、`tests/`、`test-assets/` | デモの検証スクリプト・テスト・入力素材 |
| `docs/architecture/` ほか | 元デモの構成図・検証記録 |
| `plugin/` | 別途作業中のPlugin Extensions骨格。今回の取り込みコミットには含めない |

元のREADMEだけは既存文書を保つため[参照資料](imported/demo-app-README.md)へ保存した。参照資料内のコマンド・相対パスは元リポジトリ直下を基準として読む。元資料にある公開動作・性能・AIの検証結果は取り込み元の過去記録であり、今回の環境で再実施した結果ではない。

## 配備・開発方針との関係

今回の取り込みは元の配置を維持する。現状のSites配備ルートは `apps/cloud/`、ルートのpackage.jsonはローカルデモ向けであり、09の「Sitesを直下に置く案」はまだ実現していない。配置移行を取り込み作業と同時には行わない。

Sites設定には元デモのSite IDが含まれる。ソースとして保持しているだけで、今回は登録・秘密設定・公開・再デプロイを行わない。今後の配備時に接続先と所有権を確認する。

デモにはブラウザ用ホスト画面と既存のルール/APIが含まれる。これは参考実装であり、ホストをPlugin Extensionsに置く方針や04のAPI契約へ適合済みという意味ではない。差分の整理と接続は後続作業にする。
